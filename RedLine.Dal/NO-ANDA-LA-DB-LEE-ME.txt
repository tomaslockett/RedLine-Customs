===========================================================
🏎️  REDLINE CUSTOMS - SISTEMA DE BASE DE DATOS AUTOMÁTICA 🏎️
===========================================================

Este proyecto usa Entity Framework (EF). 
La base de datos se genera y actualiza SOLA a partir de las 
clases en RedLine.BE. No hace falta crear tablas a mano.

-----------------------------------------------------------
1. CONFIGURACIÓN INICIAL (Tu Garage)
-----------------------------------------------------------
La conexión a la base de datos se configura en:
📂 RedLine.Web / Web.config

Buscá la sección <connectionStrings>. Si tu SQL Server tiene 
un nombre distinto al de tus compañeros, solo cambiá el 
"Data Source":

Ejemplo: connectionString="Data Source=.; ... " 
(El punto "." significa servidor local predeterminado).

Despues Acordate que tambien esta la conexion a la base de datos en el AbstractDAL 
Es un string de conexion Normal y Corriente 
En las dos conecciones va lo mismo asi que tranqui

-----------------------------------------------------------
2. COMANDOS DE CONSOLA (Herramientas)
-----------------------------------------------------------
Para usar estos comandos, abrí en Visual Studio:
Herramientas -> Administrador de paquetes NuGet -> Consola
En la barra de arriba de todo!!

⚠️ IMPORTANTE: En el desplegable "Proyecto predeterminado", 
seleccioná siempre: RedLine.DAL

O podes tambien click derecho en redline.dal -> Establecer proyecto de inicio
despues pone el web como inicio para que te abra la pagina web

A) SI AGREGÁS O CAMBIÁS ALGO EN LAS CLASES (BE):
   Si agregás una propiedad a una entidad o creás una clase 
   nueva, corré este comando para crear el "plano":
   
   > Add-Migration NombreDelCambio
   (Ejemplo: Add-Migration AgregadoTelefonoUsuario)

   otra opcion si no anda el tema de predeterminar el proyecto
   >Add-Migration NombreDelCambio -ProjectName RedLine.DAL -StartUpProjectName RedLine.Web

B) PARA IMPACTAR LOS CAMBIOS EN TU SQL LOCAL:
   Para que las tablas aparezcan o se actualicen en tu SQL:
   
   > Update-Database

   otra opcion si no anda el tema de predeterminar el proyecto
   >Update-Database -ProjectName RedLine.DAL -StartUpProjectName RedLine.Web -Verbose

   -Verbose es para ver los comando que hace en tiempo real te los muestra en la consola :D se puede sacar

C) SI SOS NUEVO Y QUERÉS LA BD DESDE CERO:
   Solo configurá tu Web.config y ejecutá:
   
   > Update-Database
   (Esto crea la DB, las tablas y carga los permisos iniciales).

   otra opcion si no anda el tema de predeterminar el proyecto
   Update-Database -ProjectName RedLine.DAL -StartUpProjectName RedLine.Web -TargetMigration:0

-----------------------------------------------------------
3. DATOS DE FÁBRICA (Seed)
-----------------------------------------------------------
Los permisos del Composite y Familias que vienen "de fábrica" 
se configuran en: 📂 RedLine.DAL / Migrations / Configuration.cs

Si agregás un permiso nuevo al sistema, hacelo ahí adentro 
usando "context.Permisos.AddOrUpdate(...)".
